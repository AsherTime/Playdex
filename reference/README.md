# Game reference

Drop notes, formulas, tier lists, and calculation references here for Genshin Impact and Wuthering Waves.

This folder is **not** served by the app. It exists for you and for agents working on game-calc features.

## Layout

```
reference/
├── genshin-impact/    # Genshin formulas, character notes, team calcs, etc.
└── wuthering-waves/   # WuWa formulas, character notes, team calcs, etc.
```

## What to add

- Damage formulas and stat scaling
- Character kits, rotations, and team comps
- Weapon / echo / artifact benchmarks
- Spreadsheet exports (paste as `.md` or `.json`)
- Any source material you want the codebase to follow

Use plain text formats when possible: `.md`, `.txt`, `.json`, `.csv`.

## For agents

When implementing or updating Genshin / WuWa calculators, character pages, or team logic, read the matching game folder here first before guessing formulas or metadata.
